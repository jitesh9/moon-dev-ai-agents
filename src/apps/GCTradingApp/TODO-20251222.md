# GCTradingApp Bug Fixes and Issues - 2025-12-22

## Critical Bugs Fixed

### 1. Race Condition in NextOrderId (IBKRClient.cs:38-41)
- **Problem:** `_nextOrderId++` was not thread-safe
- **Fix:** Changed to `Interlocked.Increment(ref _nextOrderId)`
- **Status:** FIXED

### 2. ClosePosition Hardcoded to 1 Contract (GCStrategyEngine.cs:370-386)
- **Problem:** Always sold 1 contract regardless of actual position size
- **Fix:** Added `_positionQuantity` field to track actual position size
- **Status:** FIXED

### 3. MACD Histogram Always Zero (GCStrategyEngine.cs:445-470)
- **Problem:** Signal line was set equal to MACD, making histogram always 0
- **Fix:** Added `_macdHistory` list and calculate proper 9-period EMA signal line
- **Status:** FIXED

### 4. Thread-Unsafe Bar List (GCStrategyEngine.cs:46-47)
- **Problem:** `_bars` list accessed from multiple threads without synchronization
- **Fix:** Added `_barsLock` object and `lock()` statements around all `_bars` access
- **Status:** FIXED

---

## High Priority Issues - FIXED

### 5. Contract Expiry Skips Current Month (IBKRClient.cs:80-117)
- **Problem:** In December, skips to February even if December contract hasn't expired
- **Fix:** Check if current month is a contract month AND day <= 25 before skipping
- **Status:** FIXED

### 6. Memory Leak - Event Handlers Not Unsubscribed (GCStrategyEngine.cs:100-110)
- **Problem:** Event handlers never unsubscribed in Stop()
- **Fix:** Added `-=` unsubscription for all three event handlers in Stop()
- **Status:** FIXED

### 7. Division by Zero (GCStrategyEngine.cs:112-127)
- **Problem:** `_peakEquity` is 0 initially, causing divide by zero
- **Fix:** Added guard `if (_peakEquity > 0)` before division
- **Status:** FIXED

### 8. Position State Not Synced with Broker (GCStrategyEngine.cs)
- **Problem:** Position flag set before order confirmed
- **Fix:** Added `_pendingEntry` and `_pendingExit` flags; position state now only
  updated on "Filled" status in OnOrderStatus callback
- **Status:** FIXED

---

## Medium Priority Issues - FIXED

### 9. Unprotected Shared State (MainForm.cs)
- **Problem:** `_state.Orders`, `_state.Fills`, `_state.Positions` modified without synchronization
- **Fix:** Added `_stateLock` object and `lock()` statements around all state collection access
- **Status:** FIXED

### 10. Strategy State Never Used (DataModels.cs:96-105)
- **Problem:** `StrategyState` classes exist but never populated/restored
- App restart loses position tracking mid-trade
- **Fix:** Added `PositionQuantity` to `StrategyState`, added `GetState()` and `OnStateChanged`
  event to `GCStrategyEngine`, MainForm now passes saved state on start and saves on changes
- **Status:** FIXED

### 11. UpdateStop Assumes Long Only (IBKRClient.cs:299)
- **Problem:** `Action = "SELL"` was hardcoded
- **Fix:** Added `action` parameter with default "SELL" for backward compatibility
- **Status:** FIXED

## Phase 1: Reliability & Robustness - IMPLEMENTED

### 1. Auto-reconnection (ConnectionManager.cs)
- **Status:** IMPLEMENTED
- Exponential backoff retry (1s, 2s, 4s, 8s, 16s, 32s, max 60s)
- Max 10 reconnection attempts before giving up
- ConnectionState enum: Disconnected, Connecting, Connected, Reconnecting
- Auto-reconnect checkbox in UI
- Re-subscribes to client events on reconnection
- Events: OnConnectionStateChanged, OnReconnectAttempt, OnLog

### 2. Position Reconciliation (PositionReconciler.cs)
- **Status:** IMPLEMENTED
- Queries actual positions from IBKR on connect
- Compares with saved StrategyState
- Shows mismatch dialog if positions don't match
- Options: Adopt broker position, Clear saved state, or Cancel
- ReconciliationResult with detailed mismatch information

### 3. Order Confirmation Tracking (OrderTracker.cs)
- **Status:** IMPLEMENTED
- TrackedOrderState: Pending, Acknowledged, PartialFill, Filled, Cancelled, Error, Timeout
- Stores permId from IBKR for each order
- Handles partial fills with FilledQuantity/RemainingQuantity tracking
- 30-second timeout detection for stuck orders
- Events: OnOrderAcknowledged, OnOrderFilled, OnOrderPartialFill, OnOrderCancelled, OnOrderError, OnOrderTimeout
- Cleanup method for old completed orders
